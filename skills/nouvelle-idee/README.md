# Skill « nouvelle idée »

Une skill pour Claude qui accompagne une idée jusqu'à un MVP testable, en huit phases : identifier le type d'idée, cadrer (avec un cadrage UX dès qu'il y a une interface), challenger en quatre rôles (avocat, procureur, comptable, juge), choisir les outils, fixer un objectif d'apprentissage, planifier le MVP, livrer le kit de démarrage, puis faire une rétro.

## Installation
- Claude Code : copiez le dossier `nouvelle-idee` dans `.claude/skills/` du projet, ou dans le dossier `.claude/skills/` de votre dossier personnel pour tous les projets.
- Claude (app ou web) : ajoutez la skill depuis les réglages des skills, en important ce dossier compressé en zip.

## Utilisation
Dites « j'ai une idée » suivi de quelques phrases. La skill pose au plus trois questions par message et ne construit rien avant que le plan soit validé.

## À adapter
Le premier paragraphe de `SKILL.md` décrit le profil de l'utilisateur, et `references/outils.md` les outils disponibles. Ajustez-les à votre contexte.
