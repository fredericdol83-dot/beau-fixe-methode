# Données ouvertes et API gratuites

Beau Fixe croise des données publiques et des API gratuites. Pouvoir valoriser ce que d'autres mettent à disposition est une vraie chance. Ces données forment un bien commun dont chacun peut se saisir, pour des usages très différents.

Vérifiez toujours la licence, le quota et les conditions d'usage de chaque source avant de l'utiliser.

## Transport
- API SNCF (moteur Navitia) et open data SNCF : horaires, itinéraires, gares. Jeton gratuit.
- OpenRouteService, sur les données OpenStreetMap : temps de route. Clé gratuite.

## Météo et climat
- Open-Meteo : prévisions et données climatiques, sans clé.
- Météo-France, stations et normales climatiques publiées sur data.gouv.fr.

## Territoire
- Géoplateforme de l'IGN : géocodage et données géographiques.
- Calendrier scolaire de l'Éducation nationale, sur data.education.gouv.fr.

## Impact et culture
- ADEME, Impact CO2 : facteurs d'émission par mode de transport.
- Wikimedia Commons : photos libres avec leurs crédits.
- Wikidata : informations sur les lieux.
- Liste du patrimoine mondial de l'Unesco.
